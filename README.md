# Midtown theatre — the Hamilton set on its stage

A scanned auditorium with the real Hamilton set and rig on its stage, the whole show auto-timed to the album,
automatic actors with the show's own choreography, a second house beside the first, a lobby and a backstage
behind both, a first-person walk, a Build mode and a lighting engine — in one HTML file, `midtown.html`
(three.js r128, no build step). `blocking.html` is the blocking editor.

Serve the repository root over http (`python -m http.server 8080`) and open `/midtown.html`.

Split out of [gms-theater](https://github.com/Jackscreations21/gms-theater-game) on 2026-10-15 with its history.
For agents: start at `CLAUDE.md`. Licences for the models are in `assets/README.md`.
