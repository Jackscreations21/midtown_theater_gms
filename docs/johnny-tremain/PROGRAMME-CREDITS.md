# Johnny Tremain — programme credits for the 3D models

The Creative Commons models the set design uses (from Jack's set-models worklist), one line each, as the programme should
print them under a heading such as **3D models used in the design**. Only models that a set piece is slotted for are listed
(`assets/johnny-tremain/models/README.md` says which piece each serves); drop a line if its model ends up unused.
CC0, Poly Haven, royalty-free, RenderHub, itch.io and Fab models need no line (a "with thanks to Poly Haven" is a kindness).
